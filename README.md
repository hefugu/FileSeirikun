# ファイル整理くん

フォルダ内のファイルを自動で分類・整理してくれるシンプルなツールです。  
拡張子や作成日ごとにまとめたいときに便利です。

---

## 機能
- 拡張子ごとに自動フォルダ分け  
  例：`.jpg` → `画像`、`.mp4` → `動画`
- 作成日ごとに自動整理（例：`2025-10` フォルダにまとめる）
- 除外パターン指定（例：`.png` を除外）
- ダーク／ライトテーマ自動切り替え（Windows設定に連動）
- 実行前に「試し整理」で内容を確認可能

---

## 動作環境
- 対応OS：Windows 10 / 11  
- Python不要（単体実行ファイル）
- 初回起動時に多少の読み込み時間があります

---

## 使い方
1. このリポジトリの [Releases] ページから  
   最新の `FileSeirikun_v1.0.zip` をダウンロードします。
2. ZIPを解凍して `FileSeirikun.exe` を実行します。
3. 整理したいフォルダを選択し、「試し整理」または「実行」をクリックします。

> ※初回起動時にWindows Defenderが警告を出す場合があります。  
> 「詳細情報」→「実行」で進めてください。
